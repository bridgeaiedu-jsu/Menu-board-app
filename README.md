# 브릿지 커피 디지털 메뉴판

손님이 테이블의 QR 코드를 찍으면 휴대폰으로 보게 되는 메뉴판 웹페이지입니다.
`index.html` 파일 하나로 되어 있어서, 설치할 것이 없습니다.

## 보는 방법

`index.html` 파일을 더블클릭하면 인터넷 브라우저에서 열립니다.

## 주요 기능

- 카테고리 버튼(전체 / 커피 / 논커피 / 디저트)으로 원하는 메뉴만 보기
- 사장님 추천(시그니처) 메뉴에 배지와 강조 표시
- 품절 메뉴는 흐리게 보이고 "오늘 품절" 표시
- 영업시간 안내와 누르면 바로 전화가 걸리는 "전화 걸기" 버튼
- 휴대폰(가로 폭 390px 기준)에 맞춘 글래스모피즘(반투명 유리) 디자인, 가로 모드도 지원

## 메뉴 고치는 방법

메뉴 정보는 `index.html` 파일 맨 위 `메뉴판` 부분에 모여 있습니다. 파일 안에 한국어 주석으로 자세한 설명이 있습니다.

```
{ 이름: "아메리카노", 가격: "4,800원", 설명: "산미가 적은 고소한 원두", 대표: false, 품절: 0 },
```

| 하고 싶은 일 | 고치는 곳 |
|---|---|
| 가격 바꾸기 | `가격: "..."` 의 따옴표 안쪽 글자 |
| 메뉴 추가하기 | 같은 칸의 메뉴 한 줄을 복사해서 아래에 붙여넣고 글자 바꾸기 |
| 사장님 추천 표시 | `대표: true` (끄려면 `대표: false`) |
| 품절 표시 | `품절: 1` (다시 판매하려면 `품절: 0`) |

고친 뒤에는 저장하고 브라우저에서 새로고침(F5)하면 반영됩니다.
줄 끝의 쉼표(`,`)와 따옴표(`"`)를 지우지 않도록 주의하세요.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 메뉴판 화면 전체 (HTML, CSS, JavaScript가 한 파일에 들어 있음) |
| `CLAUDE.md` | 이 프로젝트를 만들 때 지키는 규칙 |
| `자료/` | 기획 시트 등 참고 자료 |
